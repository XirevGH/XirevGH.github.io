Escape Sequence

A Survival FPS Game - 7 Week Project

Team Size: 7 Time: 7 Weeks UE 5 C++ 3D Pathfinding

Project Overview

Escape Sequence is an intense sci-fi horde defense shooter developed in Unreal Engine 5. Players defend high-value objectives (such as power generators and reactors) and fight to survive while navigating non-linear sci-fi combat arenas against diverse enemy archetypes.

As the lead systems and AI programmer on the project, I architected the complete enemy lifecycle, from custom 3D volumetric pathfinding for airborne units and trajectory-calculated jumping mechanics for ground swarms, to Gameplay Ability System (GAS) integration, sub-level streaming management, and Unreal Engine Subsystem architecture.

Core Technical Architecture

1. Async Multi-Threaded 3D Volumetric Pathfinding

Flying enemies required full 3D spatial mobility without being restricted by standard 2D Recast NavMeshes. I ported and modernized an Unreal Engine 4 volumetric grid plugin to UE5, constructing a dynamic 3D voxel grid where nodes check for WorldStatic and WorldDynamic collision sweeps.

To prevent frame drops when multiple aerial units calculated long-distance paths simultaneously, I completely re-engineered the pathfinder into an asynchronous worker thread pipeline:

  • Off-Thread A* Execution: Computations run inside a lightweight lambda on a background worker thread via ExecutePathfindingOnThread().
  • Atomic Search Isolation: Uses thread-safe atomic SearchID increments to prevent race conditions across parallel path requests without locking the main thread.
  • Game Thread Dispatch: Upon path resolution, an FPathfindingInternalResultBundle dispatches back onto the Game Thread via callback delegates.

2. Heuristic Optimization & Distance-Tiered Evaluation

Profiling with Unreal Insights revealed that long-range searches initially took up to 81.3 ms per path due to dense spatial voxel sweeps. I tackled this through a multi-tier optimization strategy:

  • Distance-Tiered Refresh Thresholds: Units within 10m require 1m player movement to re-path; units 10–30m require 5m; units over 30m only re-calculate if the target moves 30m or crosses threshold spheres.
  • Goal-Weighted Heuristics: Tuned the A* heuristic weight multiplier to bias exploration directly toward target vectors, reducing searched nodes by over 70%.
  • Raycast Error Correction: Solved spatial voxel false-positives by casting vertical line-of-sight traces from target bounds origin (avoiding ground clipping) to pick valid unblocked nodes.

3. Dynamic Ground AI & Physics Jump Trajectories

Ground swarms (Spider units) utilize Behavior Trees, dynamic NavLink proxy generation, and custom ballistic jump physics:

  • Dynamic Gravity Arc Lerping: Using SuggestProjectileVelocityCustomArc, jump heights dynamically modulate: jumping upwards uses steeper arcs and lower gravity ($-6000$), while jumping downwards uses flatter trajectories with heavier gravity ($-11000$) to eliminate ledge-collision hang-ups.
  • Target Surrounding & RVO Avoidance: Surrounding socket spheres around players and reactors distribute approaching enemies in a circular perimeter. Reciprocal Velocity Obstacles (RVO) avoidance was tuned to create natural pseudo-collider crowd dispersion without blocking player movement.

4. Gameplay Ability System (GAS) & Modular Combat

Specialized enemies—such as the suicide-drone "GloOrb"—were built natively with Epic's Gameplay Ability System:

  • GA_ExplodeAttack: Triggered via Behavior Tree or pre-death events, executing spherical overlap target queries.
  • GE_AOE_ExplosionDamage: Applies modular damage magnitudes mapped to custom attribute sets (1000 to enemies, 25 to defense reactors, 10 to players).
  • GC_Explode & GE_SelfDestruct: Gameplay Cues triggering spatial explosion VFX and synchronized audio.

5. Engine Subsystem Architecture & Object Pooling

Refactored core game managers from heavy in-world AActor classes into lightweight UWorldSubsystem instances (UObjectiveManager, UEnemySpawnManager):

  • Zero Scene Dependency: Direct lifecycle management accessible globally via GetWorld()->GetSubsystem<T>().
  • Trigger-Bound Object Pooling: Enemy spawners register to contextual room trigger boxes in a mapped key-value dictionary, dynamically recycling dead actor pools and scaling spawn cadence over time.
  • Polymorphic Objective Targeting: Implemented an IAttackable marking interface allowing AI to seamlessly pivot line-of-sight checks and attack routines between players and destructible generators.

⚡ Hot Reload TRASH_ Reference Invalidation:

Modifying shield parameters during runtime generated a hot-reload sweep that cleared untracked movement node pointers in reactor blueprints. I resolved this by enforcing strict UPROPERTY() ownership on dynamic sub-components and establishing deterministic runtime debug interfaces rather than altering detail panels during active PIE sessions.

🔍 Sub-Level Streaming & NavMesh Generation:

Loading modular combat zones and safe houses dynamically broke enemy NavMesh pathfinding. I structured a unified persistent navigation bounds volume spanning across all streaming levels, ensuring continuous navigation data while dynamically streaming and unloading level assets.

🎯 Flying Enemy Spline Deviation:

Flying enemies drifting off course during sharp turns were unable to recover because directions were calculated strictly between static spline points. I overhauled the path-following math to calculate steering vectors from the actor's real-time position to the upcoming node, ensuring smooth self-correcting flight lines.

Key Learnings & Takeaways

  • Low-Level Performance Profiling: Gained deep proficiency in Unreal Insights, utilizing CPU trace channels (-trace=cpu) and custom timing macros to diagnose and eliminate millisecond spikes in algorithmic loops.
  • Scalable Engine Architecture: Leveraged UWorldSubsystems and interfaces to build loosely coupled game systems that run independently of level layout dependencies.
  • Multi-Threaded Gameplay Systems: Mastered thread synchronization, async task graph dispatching, and atomic data protection in Unreal Engine C++.
