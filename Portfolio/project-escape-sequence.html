Escape Sequence

Sci-Fi Horde Defense FPS - 7 Week Team Project

Role: Lead Systems & AI Programmer Team Size: 7 Time: 7 Weeks UE 5 C++ 3D Volumetric Pathfinding Gameplay Ability System (GAS) Subsystem Architecture
View Source Code on GitHub

Game Overview

Escape Sequence is an intense sci-fi wave defense shooter developed in Unreal Engine 5. Players defend high-value objectives and fight to survive against bugs trying to destroy the system.

As the lead systems and AI programmer, I architected the complete enemy lifecycle, from modifying and integrating an asynchronous 3D volumetric pathfinding plugin for flying units and dynamic ballistic jump trajectories for ground swarms, to Gameplay Ability System (GAS) combat, DataAsset-driven spawning pipelines, and Unreal Engine Subsystem architecture.

Core Technical Architecture

1. Async Multi-Threaded 3D Volumetric Pathfinding Plugin Integration

Flying enemies required full 3D spatial mobility without being restricted by standard 2D Recast NavMeshes. I integrated an open-source UE4 3D volumetric navigation plugin and extensively modified it for Unreal Engine 5, resolving compatibility breaking changes and re-engineering its synchronous architecture into an asynchronous worker-thread pipeline:

  • Off-Thread A* Execution: Rebuilt the pathfinder to calculate routes inside a lightweight lambda on a background thread pool via ExecutePathfindingOnThread(), completely eliminating Game Thread hitches.
  • Atomic Search Identification: Engineered thread-safe atomic SearchID increments to isolate concurrent path requests across multiple aerial enemies simultaneously without data races.
  • Player Line-of-Sight Node Pruning: Added custom C++ validation (HasLineOfSightToNode in PlayerCharacter.cpp) to prune nodes hidden behind walls or outside the player's visual frustum, preventing enemies from pathing into unseen dead ends.
  • Top-Down Voxel Error Correction: Resolved false-positive collisions where voxel cubes slightly overlapped geometry by implementing downward raycast sweeps from the target origin, ensuring path endpoints always snap to valid open space.

2. Ground Swarm Ballistics, Aerial Steering & Unstuck Recovery

Ground and airborne enemies use specialized Behavior Trees and custom motion math to navigate complex multi-level geometry:

  • Dynamic Ballistic Jump Curves: Ground spiders utilize custom BP_NavLinks proxy calculations. Launch velocities dynamically scale based on jump direction: jumping upward uses steeper arcs with lower gravity (-6000), while jumping downward applies heavy gravity (-11000) to clear ledges cleanly.
  • Airborne Target NavMesh Projection: When a player jumps or is in the air, ground enemies project the player's 3D coordinate straight down onto the nearest walkable NavMesh polygon, ensuring ground swarms never stall or calculate impossible 3D paths.
  • Perlin Noise Aerial Flight: Flying Wasps utilize Perlin noise vector math in Blueprint to generate natural bob-and-weave flight patterns, steering smoothly along reused spline components (BP_FlyingEnemySplinePath).
  • Behavior Tree Unstuck Engine: Implemented a custom service and task (BTService_MonitorMoveStuck and BTTask_RelocateStuckEnemy) that monitors velocity thresholds. If an enemy becomes trapped on geometry, it is automatically recycled and relocated to an active room spawner.

3. Gameplay Ability System (GAS), Chain Lightning & Combat VFX

Player weapons and specialized enemy behaviors are engineered natively within Epic's Gameplay Ability System (GAS):

  • Chain Lightning Ability (`GA_Fire_Chaining`): Spawns an initial electric projectile that applies damage stagger, subsequently calculating nearest candidate targets and propagating chained lightning arcs between enemy sockets.
  • Suicide Drone Ability Suite: The exploding drone ("GloOrb") utilizes GA_ExplodeAttack, GE_AOE_ExplosionDamage, and GC_ChargeUpExplosion to handle suction toward targets, material parameter charge-up scaling, and dual pre-death explosion triggers.
  • Distance-Scaled Damage Numbers: Damage indicators (BP_DamageAmount) dynamically scale their screen-space offset and spread radius based on camera distance, preventing UI clutter during long-range combat.

4. Engine Subsystems, Logarithmic Spawning & System Integrity

Core game management was decoupled from in-world actors into lightweight UWorldSubsystem instances:

  • Subsystem Architecture: UObjectiveManagerSubsystem and UEnemySpawnManagerSubsystem run globally without scene dependencies, accessible via GetWorld()->GetSubsystem<T>().
  • Logarithmic Spawn Rate Scaling: The spawn manager accelerates wave intervals over time using the logarithmic formula t = T0 - k * std::logf(cycleIndex + 1) (clamped to Tmin), driving an escalating horde density curve.
  • DataAsset Wave Configuration: Created UEnemySpawnConfigurationDataAsset, allowing designers to balance enemy type ratios, max concurrent counts, and spawn intervals in the editor without triggering C++ recompilations.
  • System Integrity Loss Condition: Unmaintained defense reactors (ObjectiveBase.cpp) trigger countdown malfunction timers that directly damage System Integrity (the level's master health pool), ending the match if it reaches 0.

5. Simulation Loading, Extended Wireframe & Stencil Punchouts

Engineered visual narrative framing and low-level rendering systems:

  • Simulation Loading Narrative: Before the game begins, the world is pitch black. A custom stencil punchout shader (M_Font_StencilPunchout) and post-process material (M_Wireframe_PP) allow the interactable 3D start console and floating text to remain visible through the dark void, giving the impression of booting up a virtual simulation.
  • Bidirectional Wireframe Transition: Extended the wireframe grid animation (BP_WireframeLoad) from a one-way opening effect into a bidirectional transition. Activating the console scans the wireframe forward to load the world in, while clearing or exiting the mission plays the wireframe scan in reverse.
  • Low-Level Canvas Viewport Fading: Programmed a custom viewport client (CustomGameViewportClient.cpp) with DrawScreenFade, executing hardware-level canvas transitions during level streaming.
  • Persistent GameInstance Audio Pipeline: Maintained background music continuity across sub-level transitions in BP_GameInstance, muting SFX sound mix channels on game over while keeping ambient music playing.

Key Challenges Overcome

⏱️ High-Latency 3D Volumetric A* Searches:

Profiling with Unreal Insights revealed that long-range 3D voxel searches initially cost up to 81.3 ms on the main thread. Porting the pathfinder to an off-thread asynchronous task graph and implementing distance-tiered re-pathing thresholds reduced search overhead by over 70%.

⚡ Hot Reload TRASH_ Reference Invalidation:

Modifying shield parameters during runtime generated a hot-reload sweep that cleared untracked movement node pointers in reactor blueprints. Resolved this by enforcing strict UPROPERTY() ownership on dynamic sub-components and establishing deterministic runtime interfaces.

🔍 Sub-Level Streaming & NavMesh Generation:

Dynamically opening and closing gates to the different areas broke enemy NavMesh pathfinding. Structured a unified persistent navigation bounds volume spanning across all streaming levels, ensuring continuous navigation data while dynamically streaming and unloading level assets.

🛑 AI Navigation Stalls on Multi-Level Geometry:

Enemies occasionally became trapped behind dynamic obstacles or steep geometry. Engineered an automated Behavior Tree recovery engine (BTTask_RelocateStuckEnemy) that monitors stationary timers and recycles trapped actors back into active room pools.

Project Outcome

Delivered over the 7-week development cycle, the game achieved:

  • An asynchronous 3D volumetric pathfinding plugin running seamlessly across multi-threaded worker pools
  • Robust Behavior Tree AI with custom ballistic NavLink jumping and Perlin noise flight steering
  • Decoupled Unreal Subsystem architecture supporting DataAsset-driven wave spawning and object pooling
